# 機關解謎系列（暫名）

3D 實體機關解謎遊戲的元件庫與系列企劃：推、轉、插、撥、搖，一層層打開一只機關盒。

> **核心精神：機關是積木，關卡是資料，題材是外衣。**

## 緣起

先用單一 HTML 做了一個原型「五重機關盒」，驗證了網頁 3D 機關解謎在手感和畫面上都成立。接下來要把它拆成可重組的機關元件庫，搭配可自動驗證的關卡格式，再套上市場上還沒人用過的題材，做成系列作。

## 目前進度

- **v0 原型**：線上試玩 <https://mechanism-puzzle.vercel.app>；本機可直接用瀏覽器開 [`prototype/v0-five-locks.html`](prototype/v0-five-locks.html)（需要網路載入 Three.js 與字型）
  - 五道機關：寄木滑板、連環轉盤、齒輪齒條、密碼滾筒、鑰匙鎖
- **規劃書**：[`docs/planning.md`](docs/planning.md)（v0.1 草案）
  - 解謎公式的解構、關卡依賴圖與描述格式、元件庫分層與契約、可擴充性、可變化性、題材評估框架、開發路線
